# Italian, English and Russian

The shared React interface uses `lib/i18n/provider.tsx` with typed `it`, `en` and
`ru` locales and a complete paired EN/RU dictionary in `lib/i18n/messages.json`.
Italian source keys provide the original locale. Components translate their
rendered labels through the React context; no DOM rewriting or remote translation
service is used.

Locale precedence on first load: `?lang=` query, saved `pergola.locale` preference,
browser language, Italian fallback. The switch updates the URL, preference and
document language. Storage-disabled browsers still support switching.

Money and dates use Intl locale formatting. Product IDs, catalogue tables,
prices, quote numbers and saved snapshots are never translated or repriced.
Manufacturer model names and material brands are preserved. Family descriptions,
options, colours and technical conditions are localized. Extracted source
descriptions remain available in a separately labelled Italian original section.
Free customer/company text remains as entered.

Vercel PDF links include `?lang=it|en|ru`. The gateway first fetches the existing
quote snapshot with the same visitor/admin authorization, then generates a Unicode
PDF in that language. It never bypasses quote ownership or recalculates saved
amounts. Links without a language retain the original backend PDF behavior.

The Italian, English and Russian interfaces use the same public access rules;
the administrator workspace remains protected.
