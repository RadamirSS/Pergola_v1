# Acceptance scenarios

- California 300 x 200 cm, white, quantity 1, no accessories: base EUR 680.00,
  VAT EUR 149.60, total EUR 829.60 (PDF p.51).
- Summer Winter Addossata, 2 spans, 500 x 300 cm: EUR 7891.00 before VAT (p.126),
  saved as a review request until model approval.
- Veneziana 35 mm, 50 x 100 cm: physical area 0.50 m², billable 1.50 m²,
  base EUR 58.50 (p.234). Width below 40 cm is unavailable.
- Vertical Atene, 200 x 100 cm: minimum billable height 200 cm, billed 4.00 m²,
  base EUR 136.00 (p.236).
- Special/red California 245 x 250 cm cannot be issued as an ordinary offer.
- Olanda LED prices and ordinary prices remain separate. 5000 with/without valance
  remains separate even where the depth is identical.
- Unknown/missing price combinations, invalid amounts and incompatible option
  groups block save with a clear error. No guessed price is generated.
- Save a project, refresh/reopen the browser, open it in the archive and download
  its PDF. Update company/catalogue settings: the old snapshot remains unchanged.
- Repeating one save request key creates only one record. Quote IDs remain unique
  after cancellations and concurrent requests.
- Complete company details before issuing; internally confirm only an issued,
  unexpired document. Confirmation never sends anything to a supplier.
- AI shows an unavailable state. No image upload control or AI request is active.

The automated suite validates the numerical contract. Browser QA validates controls,
responsive presentation, persistence, PDF download and the unavailable AI state.
